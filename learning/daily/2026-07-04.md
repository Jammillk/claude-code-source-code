## 关键收获

### Claude Code 的核心循环

```
User → messages[] → Claude API → response
  ├─ stop_reason == "tool_use"? → execute tools → append tool_result → loop
  └─ stop_reason != "tool_use"  → return text result
```

这就是所有 AI Agent 的基础模式。Claude Code 在此基础上叠加了 12 层生产级机制：
权限控制、子代理、上下文压缩、任务系统、MCP 协议等。

### 关键文件

- `src/query.ts` — 主循环，~785KB，整个项目的核心
- `src/Tool.ts` — 工具接口，`buildTool()` 工厂函数
- `src/QueryEngine.ts` — 对主循环的封装，提供 SDK 接口
- `src/services/compact/` — 上下文压缩策略
- `src/tools/AgentTool/` — 子代理生成
